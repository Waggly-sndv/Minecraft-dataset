# Análisis de Dataset de Minecraft

## Descripción

Este proyecto analiza un dataset relacionado con Minecraft que contiene preguntas,
instrucciones y respuestas.

## Dataset

El dataset contiene 10,000 registros y 3 columnas:

- instruction
- input
- output

## Herramientas utilizadas

- Python
- Pandas
- SQLite
- SQL
- Matplotlib
- Google Colab
- GitHub

## Análisis realizado

Se realizaron:

- Exploración de los datos
- 10 consultas SQL
- Análisis de texto
- 5 visualizaciones
- Conclusiones sobre los resultados

## Visualizaciones

Se utilizaron diferentes tipos de gráficas:

- Gráfica de pastel
- Boxplot
- Gráfica de dispersión
- Gráfica de barras
